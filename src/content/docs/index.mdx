## Why AetherEngine

<div class="landing-why">
  <div>
    <h3>Plays nearly everything</h3>
    <p>MKV, MP4, AVI, WMV, MPEG-TS, DVD and Blu-ray ISOs, and every codec FFmpeg knows.</p>
  </div>
  <div>
    <h3>Keeps Apple's picture and sound</h3>
    <p>Hardware decoding, the real Dolby Vision display switch and Dolby Atmos passthrough, the way Apple's own player does it.</p>
  </div>
  <div>
    <h3>You own the UI</h3>
    <p>One view and a few <code>async</code> methods. No built-in controls, no analytics. Nothing leaves the device.</p>
  </div>
</div>

## A player in a few lines

```swift
// Package.swift
.package(url: "https://github.com/superuser404notfound/AetherEngine", from: "7.62.0")
```

```swift
import AetherEngine
import SwiftUI

let player = try AetherEngine()

struct PlayerView: View {
    var body: some View { AetherPlayerSurface(engine: player) }
}

try await player.load(url: videoURL)
player.play()
```

The [host guide](/guides/host-guide/) takes it from here: tracks, subtitles, live TV and the tvOS setup.

## What it handles

<CardGrid>
  <Card title="HDR and Dolby Vision" icon="seti:video">
    HDR10, HDR10+, HLG and Dolby Vision Profiles 5, 7, 8 and AV1 Profile 10, with Match Content on Apple TV. [More](/guides/features/#hdr-and-dolby-vision)
  </Card>
  <Card title="Dolby Atmos and height channels" icon="seti:audio">
    E-AC-3 Atmos passed through to receivers and AirPods. Lossless height channels from TrueHD and DTS:X as an option. [More](/guides/features/#dolby-atmos)
  </Card>
  <Card title="Every format" icon="seti:default">
    Hardware decode for H.264, HEVC and AV1, software decode for everything else. Files, discs and on-demand DASH. [More](/guides/features/#video)
  </Card>
  <Card title="Subtitles of every kind" icon="document">
    Text, ASS, PGS, DVB, DVD, teletext and closed captions, external files, and subtitles that survive Picture in Picture and AirPlay. [More](/guides/features/#subtitles)
  </Card>
  <Card title="Live TV and DVR" icon="seti:clock">
    HLS ingest, timeshift, recording over the same connection, and recovery when a channel breaks. [More](/guides/features/#live-tv-and-dvr)
  </Card>
  <Card title="Any source" icon="seti:folder">
    URLs, your own byte reader, SMB shares, and servers with self-signed certificates. [More](/guides/features/#inputs-custom-readers-smb-certificates)
  </Card>
</CardGrid>

## How it compares

| | AetherEngine | AVPlayer | VLC / mpv |
| --- | --- | --- | --- |
| **Formats** | Nearly all | Apple's only | Nearly all |
| **Dolby Vision display** | Yes | Partly | No |
| **Atmos passthrough** | Yes | Yes | No |
| **Your own UI** | Yes | Yes | No |
| **App Store** | Yes | Yes | VLC only |
